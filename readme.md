Javascript é uma linguagem de programação leve que os desenvolvedores usam para criar interações mais dinâmicas ao desenvolver páginas da Web, aplicativos, servidores, jogos, etc. 

Ele cria elementos para melhorar a interação dos visitantes do site com as páginas da web, como menus suspensos, gráficos animados e cores de fundo dinâmicas.

Geralmente o Javascript é usado como complemento às linguagens com HTML, CSS e PHP,  mas a  linguagem funciona bem também com CSS na formatação de elementos HTML. No entanto, ainda mantém a interação do usuário, algo que o CSS não pode fazer sozinho.



O JavaScript foi criado em 1995 por Brendan Eich em apenas 10 dias, a pedido da Netscape, para dar dinamismo às páginas da web.A Criação e os Primeiros Anos

1995: Brendan Eich desenvolveu a linguagem inicialmente chamada de Mocha, depois rebatizada para LiveScript, e finalmente JavaScript como estratégia de marketing para pegar carona no sucesso do Java.

1996: A Microsoft lançou o JScript para o Internet Explorer, gerando problemas de compatibilidade entre navegadores diferentes.Padronização e Evolução

1997: A Netscape levou a linguagem para a ECMA International para criar um padrão universal chamado ECMAScript.

2005: Surgiu o conceito de Ajax, permitindo atualizar partes de páginas web sem recarregar o site inteiro.

2008: O Google lançou o navegador Chrome com o motor V8, tornando a execução de códigos muito mais rápida.

2009: Foi lançado o Node.js, permitindo rodar JavaScript também no servidor e não apenas no navegador.

2015: O lançamento do ES6 (ECMAScript 2015) trouxe grandes melhorias e modernizou a escrita da linguagem, com atualizações anuais desde então.
